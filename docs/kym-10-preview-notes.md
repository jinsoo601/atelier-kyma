# KYM-10 page design preview

The Next.js implementation is tracked in [KYM-10 implementation state](./kym-10-implementation.md). This HTML file remains the approved visual reference.

Open [the interactive HTML mock](./kym-10-page-preview.html) in a browser. Use the page selector above the gallery header, the site navigation, or the links within a page. Resize the browser to review the phone layout. This file is a design proposal, not a production route; its checkout and inquiry controls do not send anything.

The homepage continues the approved KYM-8 Image-led direction. The mock covers home, the artist list and two artist details, artwork list and detail, all 12 exhibition archive entries and one detailed exhibition example, gallery introduction, and contact/inquiry. The current logo is retained. Both artist details use an on-page grid with six images initially visible (three columns by two rows on desktop; two columns by three rows on phones) and a "더보기" control to reveal the remainder: 12 existing 성석진 images and 8 existing 이인숙 images are all available after expansion. The approved ₩2,000,000 pilot work appears separately in the 성석진 grid and is the only grid item linked to a sale detail; the existing portfolio images do not imply current availability. The artist, artwork, and exhibition images are framed to show complete works without clipping. The About example visibly keeps Korean, English, and French.

The pilot pottery photo comes from `assets/pilot/suk-jeen-sung-cheonghwa-baekgeum-dot-moon-jar.jpeg`. The artist gallery images are local copies of the gallery's existing assets, staged under `docs/kym-10-assets/` solely for this offline mock; `artist-gallery-manifest.json` records their source and existing captions. The 이인숙 preview image uses the same local source. The exhibition example uses existing checked-in images from `public/jeong-hyun-ha-solo-exhibition/`. Replace preview images through the planned asset workflow before launch; the mock does not introduce a new Sanity dependency.

Content labeled “갤러리 확인 후 입력” and short sample introductions are placement examples. The full artist biographies, three About passages, all exhibition details, delivery terms, and artwork metadata still need the content and owner review described in KYM-3, KYM-11, KYM-12, and KYM-16. Only the 하정현 exhibition row opens the detailed exhibition example in this mock; all 12 rows will receive their own production detail pages.

After layout review, implement the approved templates in the App Router using repository content records from KYM-7, keeping the existing Pages Router routes in place during migration. The artist template should render its complete ordered portfolio image list, showing six initially and revealing all remaining images on demand; only works explicitly marked for sale should show a price or link to checkout. The homepage image and text will be read from one featured-content record so it can be changed without editing the template.
